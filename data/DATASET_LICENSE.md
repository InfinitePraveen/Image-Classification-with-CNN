# Dataset Terms

The project source code is MIT licensed, but the Kaggle dataset is governed by its own dataset/competition terms.

Before redistributing downloaded data, review the current Kaggle page and the dataset's license/terms:

- Kaggle CIFAR-10 dataset: https://www.kaggle.com/datasets/ayush1220/cifar10
- Kaggle CIFAR-10 competition: https://www.kaggle.com/competitions/cifar-10

The original CIFAR-10 collection is attributed to Alex Krizhevsky, Vinod Nair and Geoffrey Hinton.
