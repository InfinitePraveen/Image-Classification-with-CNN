# Troubleshooting

## Model not found

Run notebooks 04 and 06 to train and export the Keras model.

## TensorFlow installation error

Use a supported Python version and follow the TensorFlow installation guidance for your operating system.

## Upload rejected

The app accepts PNG, JPEG and WEBP images up to 5 MB.

## Low accuracy

Check normalization, labels, augmentation strength, training duration and learning rate.
