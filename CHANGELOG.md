# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-25

### Added
- Initial CNN image-classification project.
- Kaggle CIFAR-10 dataset documentation.
- Six-stage Jupyter notebook workflow.
- TensorFlow/Keras CNN architecture.
- Training data augmentation.
- Model evaluation and confusion-matrix workflow.
- Flask inference web application.
- Responsive HTML/CSS/JavaScript frontend.
- Upload validation and prediction endpoint.
- Contribution guidelines.
- Project documentation.
- Automated tests and GitHub Actions configuration.

### Notes
- The Kaggle dataset and generated Keras model are intentionally excluded from the repository's Git history.
- Run the training/export notebook to create `models/cifar10_cnn.keras`.
